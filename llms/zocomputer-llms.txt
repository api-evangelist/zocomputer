# Zo Computer Documentation

> Zo is an intelligent cloud computer: store your files, connect your tools, and research or build practically anything with AI. These docs cover using Zo, its built-in tools, hosting, and the API.

## Instructions for AI agents
- Every docs page is available as Markdown: append `.md` to its URL, or request it with `Accept: text/markdown`.
- Start with the Introduction for the product model; the Tools pages document every built-in tool and its parameters.
- The public HTTP API is small — see the API reference pages; the OpenAPI spec is at https://www.zo.computer/docs-assets/openapi.json.
